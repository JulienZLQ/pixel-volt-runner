# 像素闪电跑酷

一个零依赖的手机端 HTML5 Canvas 像素跑酷小游戏。

## 打开方式

直接用浏览器打开 `index.html`。

## 玩法

- 点击画面或“跳跃”：跳过地面障碍。
- 按住“下滑”：躲避空中障碍。
- 闪电能量满后点“冲刺”：短时间无敌并加速。
- 收集金币、闪电和磁铁道具，提高分数与连击。
- “玩法”按钮会弹出触控说明；“皮肤”功能暂未开放。

## 素材

角色、动作帧、金币、道具、障碍、城市背景和粒子效果都在 `main.js` 中用像素块绘制，没有外部图片依赖。

已绘制动作：

- 待机：首页 CSS 像素角色。
- 奔跑：两帧循环。
- 跳跃：腾空姿态。
- 下滑：低身滑行动作。
- 冲刺：电光眼和拖尾。
- 庆祝：结算页 CSS 像素角色。

## 触控优化

游戏区域和按钮会阻止长按选中文字、系统菜单和页面回弹，适合手机端持续按住下滑或快速点击跳跃。
